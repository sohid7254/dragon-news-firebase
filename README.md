# 📰 Dragon News Project

Dragon News is a modern React-based news portal application. It provides category-based news browsing, detailed article views, and user authentication. The project is styled with TailwindCSS and DaisyUI, and integrates Firebase for backend services.

## 📖 Project Description

Dragon News is a modern, React-based news portal application that delivers the latest headlines and articles in an engaging, user-friendly interface. Built with **React 19**, **TailwindCSS**, and **DaisyUI**, it provides a responsive design that works seamlessly across devices. The project integrates **Firebase** for authentication and backend services, while **React Router** powers smooth navigation between categories and detailed news pages.  

Additional libraries like **Date-fns** help manage and format dates, **React Fast Marquee** creates dynamic scrolling headlines, and **React Icons** enrich the UI with scalable icons. Together, these technologies make Dragon News a scalable, secure, and visually appealing platform for reading and managing news content.

## 📦 Dependencies

This project uses the following major dependencies:

- **@tailwindcss/vite** `^4.1.14` – TailwindCSS integration with Vite  
- **daisyui** `^5.3.7` – TailwindCSS component library  
- **date-fns** `^4.1.0` – Modern JavaScript date utility library  
- **firebase** `^12.4.0` – Authentication, database, and hosting services  
- **react** `^19.1.1` – Core React library  
- **react-dom** `^19.1.1` – React DOM rendering  
- **react-fast-marquee** `^1.6.5` – Smooth scrolling marquee component  
- **react-icons** `^5.5.0` – Popular icon packs for React  
- **react-router** `^7.9.4` – Routing and navigation for React apps  
- **tailwindcss** `^4.1.14` – Utility-first CSS framework

## 🚀 Features
- 📌 **Dynamic Routing** – Smooth navigation using React Router  
- 📰 **Category-Based News** – Browse news by different categories  
- 🔍 **News Details Page** – Dedicated view for each article  
- 👤 **Authentication System** – Login/Register functionality with Firebase  
- 📱 **Responsive Design** – Mobile-friendly UI with TailwindCSS + DaisyUI  
- 🎠 **Marquee Headlines** – Scrolling news ticker using react-fast-marquee
